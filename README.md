# postSPIT

`postSPIT` is a Python package for post-processing, analysing, and plotting microscopy results generated with SPIT.

The package supports two main analysis routes:

1. **Tracked-data analysis** — work directly with the tracks and colocalization results generated by SPIT.
2. **Cell and combined analysis** — analyse cells and protein clusters, combine clusters with tracked localizations, remove spots inside clusters, retrack the remaining spots, and rerun colocalization.

The package also includes plotting classes and dataset-level wrappers for applying the same analysis to multiple experimental conditions and runs.

## Installation

From the repository root, install the package in editable mode:
1. Clone repository
2. in the command line move to the folder:
```bash
cd Documents/Github/Immune_cell_TIRF_analysis
```
Change folder accordingly
3. Install (make sure to include the dot, it is '-e .'):
```bash
python -m pip install -e .
```

The code also imports SPIT and Picasso functionality. Make sure the packages providing `spit` and `picasso` are installed in the same Python environment:
[SPIT repository](https://github.com/GanzingerLab/SPIT)
[picasso repository](https://github.com/jungmannlab/picasso) -- use the version required by SPIT

## Choosing an analysis route

| Goal | Recommended class |
|---|---|
| Open and analyse the original SPIT tracks from one run | `Single_tracked_folder` |
| Analyse original SPIT tracks across several conditions and runs | `Dataset_tracked_folder` |
| Analyse cells, protein clusters, or cell maturation in one run | `Cell_Analyzer` |
| Combine cluster analysis with tracked localizations in one run | `Combined_analysis` |
| Run cell and combined analyses across a complete dataset | `Dataset_combined_analysis` |
| Manually construct an object from already loaded images and DataFrames | `Tracked_image` |

# Route 1: analysing original SPIT tracks

Use this route when you want to work directly with the tracking and colocalization outputs generated by SPIT.

## One run: `Single_tracked_folder`

`Single_tracked_folder` finds and loads the images, tracked localizations, track statistics, and colocalization results available in one run folder.

```python
from postSPIT import Single_tracked_folder

folder = r"path/to/Run00001"

tracked = Single_tracked_folder(
    folder,
    ch0_hint="488nm",
    ch1_hint="561nm",
).open_files()
```

The wavelength hints are useful when channel information cannot be obtained from a **colocalization** YAML file. They should match the wavelength text used in the filenames.

To inspect which images and tracking files are available before opening them:

```python
from postSPIT import Single_tracked_folder

loader = Single_tracked_folder(
    folder,
    ch0_hint="488nm",
    ch1_hint="561nm",
)

loader.validate()
tracked = loader.open_files()
```

`open_files()` returns a `Tracked_image` object.

## Inspecting the loaded data

The main DataFrames are available as attributes:

```python
tracks_ch0 = tracked.tracks0
stats_ch0 = tracked.stats0

tracks_ch1 = tracked.tracks1
stats_ch1 = tracked.stats1

colocalized_tracks = tracked.coloc_tracks
colocalized_stats = tracked.coloc_stats
```

For single-channel data, the ch1 and colocalization attributes may not be available.

## Plotting tracks

Track identifiers must be passed as a list:

```python
plot = tracked.plot_tracks([1704], channel="ch0")
```

For several tracks:

```python
plot = tracked.plot_tracks([1704, 1712, 1730], channel="ch0")
```

To plot colocalized tracks, pass one or more colocalization IDs:

```python
plot = tracked.plot_colocs([248])
```

To plot the intensity traces of one colocalization event:

```python
plot = tracked.plot_intensity_coloc(
    248,
    legend_loc="upper left",
    legend_0="Channel 0",
    legend_1="Channel 1",
)
```

Plots can be modified before saving:

```python
plot.set_xlim(0, 120)
plot.save_plot("output_plot.pdf", dpi=300)
```

## Extracting diffusion coefficients

```python
diffusion = tracked.extract_Ds(
    min_len=10,
    channel="ch0",
)
```

`min_len` is the minimum accepted track length. The method returns the available track identifier, cell identifier, and `D_msd` values after filtering invalid diffusion coefficients.

## Extracting dwell times

```python
dwell = tracked.extract_dwell(
    frame_rate=0.1,
    min_len=10,
    max_dist=250,
    ref="ch0",
)
```

Parameters:

- `frame_rate`: frame interval used to convert frames to seconds.
- `min_len`: minimum length of a colocalization event.
- `max_dist`: maximum distance in nanometres used to retain a colocalized localization.
- `ref`: reference channel, either `"ch0"` or `"ch1"`.

## Complete dataset: `Dataset_tracked_folder`

Use `Dataset_tracked_folder` to analyse original SPIT tracks across several experimental conditions and runs.

```python
from postSPIT import Dataset_tracked_folder

dataset = Dataset_tracked_folder(r"path/to/experiment")
```

All detected conditions are selected by default. These are the **first** subfolders found within "path/to/experiment", as many conditions as subfolders. Within those subfolders you can include as many extra subfolders as you want, siunce the code will look for Run folders within all of them. To work with only some conditions, pass their indices:
Check conditions:
```python
print(dataset.conditions)
```
Select conditions:
```pyhton
dataset.select_conditions([0, 2])
```
### Validate the tracking settings

```python
dataset.validate()
```

### Check how many runs contain colocalized tracks

```python
dataset.count_cotracked()
tracked_folders = dataset.tracked_folders
```

### Count tracks and colocalized tracks

```python
counts = dataset.count_number_cotracks()
summary = dataset.summary_count_number_cotracks()
```

Run `count_number_cotracks()` before `summary_count_number_cotracks()`.

### Extract diffusion coefficients across the dataset

```python
diffusion, boxplot = dataset.get_Ds(
    min_len=10,
    channel="ch0",
)
```

### Extract dwell times across the dataset

```python
dwell, histogram = dataset.get_dwell(
    min_len=10,
    ref="ch0",
)
```

The returned plotting object can be edited and saved:

```python
histogram.set_xlim(0, 120)
histogram.save_plot("dwell_times.pdf", dpi=300)
```

# Route 2: cell, cluster, and combined analysis

Use this route when you want to analyse cells or protein clusters, predict cell maturation, or relate tracked localizations to protein-cluster masks.

There are two levels:

- `Cell_Analyzer` performs cell, cluster, and maturation analysis.
- `Combined_analysis` joins those results with the original SPIT tracks.

## Cell and cluster analysis: `Cell_Analyzer`

```python
from postSPIT import Cell_Analyzer

cells = Cell_Analyzer(
    folder=r"path/to/Run00001",
    ch0_wl="488nm",
    ch1_wl="561nm",
)
```

The class loads the available image channels, obtains the spatial calibration, separates cells using the available ROI information, and reloads previously saved analysis results when possible.

### Detect and analyse protein clusters

```python
(
    cluster_masks,
    cluster_measurements,
    cluster_summary,
    linked_clusters,
    linked_cluster_summary,
) = cells.analyze_clusters_protein(
    min_size=80,
    ch="ch0",
    th_method="li_local",
    global_th_mode="max",
    window_size=15,
    p=2,
    q=6,
    save_videos=False,
    overwrite=False,
)
```

Important parameters:

| Parameter | Meaning | Accepted or typical values |
|---|---|---|
| `ch` | Channel used for cluster detection | `"ch0"`, `"ch1"`, or an available wavelength key |
| `min_size` | Minimum cluster area in pixels | Experiment-dependent |
| `th_method` | Thresholding method | `"li"`, `"li_local"`, `"otsu"`, `"otsu_local"` |
| `global_th_mode` | Image representation used for the global threshold | `"max"`, `"full"`, `"median"`, `"last"` |
| `window_size` | Radius/window used by the local threshold | Experiment-dependent |
| `save_videos` | Save cell-centred result videos | `True` or `False` |
| `overwrite` | Recalculate results already loaded or saved | `True` or `False` |

### Predict cell maturation

Maturation prediction requires a compatible trained model. See [Nguyen2026_code_repository](https://github.com/GanzingerLab/Nguyen2026_code_repository) for training code and example. 

```python
maturation = cells.predict_maturation(
    model,
    ch="ch1",
    N_rolling=5,
    r2_thresh=0.75,
    low_thresh=0.4,
    high_thresh=0.6,
    save_plot=False,
    overwrite=False,
)
```

A custom frame-preprocessing function can be passed with `preprocess_frame_func` when the model requires preprocessing different from the package default.

## Combining clusters and tracks: `Combined_analysis`

`Combined_analysis` loads both a `Single_tracked_folder` and a `Cell_Analyzer` for the same run.

```python
from postSPIT import Combined_analysis

analysis = Combined_analysis(
    folder=r"path/to/Run00001",
    ch0_hint="488nm",
    ch1_hint="561nm",
)
```

Previously saved combined-analysis results are reloaded automatically when available.

## Standard combined workflow

### Step 1: detect clusters and remove spots inside them

```python
results = analysis.combine_spots_clusters(
    min_size=80,
    ch="ch0",
    th_method="li_local",
    global_th_mode="max",
    window_size=15,
    p=2,
    q=6,
    save_videos=False,
    overwrite=False,
)
```

This method:

1. Runs or reloads cluster analysis for the selected channel.
2. Removes tracked localizations that fall inside detected clusters.
3. Calculates local spot intensities.
4. Combines spot measurements with cluster statistics.
5. Saves the filtered localizations and summary results.

The returned tuple contains cluster masks, cluster measurements, cluster-and-spot statistics, linked clusters, linked-cluster statistics, and the filtered spots.

Run the method separately for both channels when both channels must be cluster-filtered:

```python
analysis.combine_spots_clusters(ch="ch0")
analysis.combine_spots_clusters(ch="ch1")
```

### Step 2: retrack the remaining spots

```python
analysis.retrack(overwrite=False)
```

This uses the relevant SPIT tracking settings to relink localizations outside the detected clusters.

### Step 3: rerun colocalization

```python
analysis.recoloc_tracks(overwrite=False)
```

This reruns the SPIT colocalization procedure using the retracked localizations, and reusing the relevant SPIT settings.

For dual-channel filtered colocalization, both channels must have been filtered and retracked first. 

### Step 4: predict maturation when maturation filtering is required

Filtered diffusion and dwell methods use maturation categories. Run maturation prediction on the channel needed for maturation analysis:

```python
analysis.clusters.predict_maturation(
    model,
    ch="ch1",
    overwrite=False,
)
```

### Step 5: extract filtered diffusion coefficients

```python
diffusion = analysis.extract_Ds_filtered(
    mature_class=1,
    min_len=10,
    ch="ch0",
)
```

This requires:

- retracked spots from `retrack()`;
- maturation results from `analysis.clusters.predict_maturation()`.

Accepted maturation categories are `0`, `1`, `2`, and `3`.

### Step 6: extract filtered dwell times

```python
dwell = analysis.extract_dwell_filtered(
    mature_class=1,
    frame_rate=None,
    min_len=10,
    max_dist=250,
    ref="ch0",
    ch_maturation_selection="ch1",
)
```

This requires:

- filtered colocalization results from `recoloc_tracks()`;
- maturation results from `analysis.clusters.predict_maturation()`.

When `frame_rate=None`, the frame interval is read from the run's `result.txt`. Pass a numeric value to override automatic detection.

`ref` selects the reference channel used for the dwell-time calculation. `ch_maturation_selection` selects the channel whose maturation classification is used to filter cells.

The standard dependency order is therefore:

```text
combine_spots_clusters() for the required channel(s)
                    |
                    v
                retrack()
                    |
                    v
             recoloc_tracks()
                    |
                    +--------------------------+
                    |                          |
                    v                          v
clusters.predict_maturation()    filtered track/colocalization results
                    |                          |
                    +-------------+------------+
                                  |
                                  v
        extract_Ds_filtered() and/or extract_dwell_filtered()
```

## Complete dataset: `Dataset_combined_analysis`

Use `Dataset_combined_analysis` to apply cell and combined analyses to all selected runs in a dataset.

```python
from postSPIT import Dataset_combined_analysis

dataset = Dataset_combined_analysis(r"path/to/experiment")
```

The class detects conditions and run folders automatically and reads the channel wavelengths from available colocalization metadata.

Similarly to the tracked_dataset, all conditions are selected initially. To analyse a subset:

```python
print(dataset.conditions)
dataset.select_conditions([0, 1])
```

Select conditions before running dataset analyses.

### Validate the dataset settings

```python
dataset.validate()
```

### Run cluster analysis across the selected runs

```python
dataset.analyze_clusters_protein(
    min_size=80,
    ch="ch0",
    th_method="li_local",
    global_th_mode="max",
    save_videos=False,
    overwrite=False,
)
```

### Predict maturation across the selected runs

```python
dataset.predict_maturation(
    model,
    ch="ch1",
    overwrite=False,
)
```

### Combine clusters and spots across the selected runs

```python
dataset.combine_spots_clusters(
    min_size=80,
    ch="ch0",
    th_method="li_local",
    global_th_mode="max",
    save_videos=False,
    overwrite=False,
)
```

Run this once for each channel that must be filtered.

### Retrack and rerun colocalization

```python
dataset.retrack(overwrite=False)
dataset.recoloc_tracks(overwrite=False)
```

### Count tracks and colocalized tracks

The same dataset class can count either the original SPIT tracks or the filtered tracks:

```python
tracked_counts = dataset.count_number_cotracks(
    source="tracked",
    min_len=5,
)

filtered_counts = dataset.count_number_cotracks(
    source="filtered",
    mature_class=1,
    min_len=5,
    ch_maturation_selection="ch1",
)
```

Summarize the latest counting result by condition:

```python
summary = dataset.summary_count_number_cotracks()
```

### Extract diffusion coefficients

From the original SPIT tracks:

```python
diffusion, boxplot = dataset.get_Ds(
    source="tracked",
    min_len=10,
    ch="ch0",
)
```

From cluster-filtered and maturation-filtered tracks:

```python
diffusion, boxplot = dataset.get_Ds(
    source="filtered",
    mature_class=1,
    min_len=10,
    ch="ch0",
)
```

### Extract dwell times

From the original SPIT colocalization results:

```python
dwell, histogram = dataset.get_dwell(
    source="tracked",
    min_len=10,
    frame_rate=0.1,
    max_dist=250,
    ref="ch0",
)
```

From filtered and maturation-selected colocalization results:

```python
dwell, histogram = dataset.get_dwell(
    source="filtered",
    mature_class=1,
    min_len=10,
    frame_rate=0.1,
    max_dist=250,
    ref="ch0",
    ch_maturation_selection="ch1",
)
```

The method first tries to read the frame interval automatically. If automatic detection fails, it uses the supplied `frame_rate` value and prints the reason for the failure.

### Summarize maturation classifications

```python
maturation_counts = dataset.count_maturation(ch="488nm")
```

Use the wavelength key corresponding to the channel for which maturation was predicted.

### Review failed runs

Dataset operations continue when an individual run fails. The error is printed and the failed run is recorded.

```python
dataset.print_failed_folders()
```

# Plotting utilities

The following plotting classes can be imported directly from `postSPIT`:

```python
from postSPIT import (
    Plotter,
    LinePlotter,
    ScatterPlotter,
    HueBoxPlotter,
    BoxPlotter,
    HistogramPlotter,
    TrackPlotter,
)
```

Most analysis methods that generate plots return one of these objects. The objects can be adjusted before display or saving:

```python
plot.set_xlim(0, 100)
plot.set_ylim(0, 20)
plot.set_grid(True)
plot.save_plot("analysis.pdf", dpi=300)
```

# Common parameters

| Parameter | Meaning |
|---|---|
| `ch` / `channel` | Channel to analyse: usually `"ch0"` or `"ch1"` |
| `ref` | Reference channel used for dwell-time analysis |
| `source` | Use original SPIT results (`"tracked"`) or cluster-filtered results (`"filtered"`) |
| `min_len` | Minimum accepted track or colocalization length |
| `max_dist` | Maximum accepted distance for colocalized localizations, in nanometres |
| `frame_rate` | Frame interval used to convert frame numbers to time |
| `min_size` | Minimum accepted protein-cluster size in pixels |
| `mature_class` | Cell maturation category used for filtering: `0`, `1`, `2`, or `3` |
| `overwrite` | Recalculate results even when previous results are available |

# Troubleshooting

## Check the contents of one run

```python
Single_tracked_folder(folder).validate()
```

## Check dataset-level tracking or colocalization settings

```python
Dataset_tracked_folder(dataset_folder).validate()
Dataset_combined_analysis(dataset_folder).validate()
```

## A combined-analysis object prints a warning during initialization

`Combined_analysis` tries to load both tracked files and cell/ROI information. A warning indicates that one of these components could not be initialized. Read the full printed error and check the corresponding SPIT outputs.

## A dataset analysis skips one run

Dataset-level methods are designed to continue processing other runs even when one fails. The folder, operation, exception type, and exception message are printed. For combined datasets, review the recorded failures with:

```python
dataset.print_failed_folders()
```

## Filtered diffusion extraction says maturation is missing

Run maturation prediction first:

```python
analysis.clusters.predict_maturation(model, ch="ch1")
```

For a dataset:

```python
dataset.predict_maturation(model, ch="ch1")
```

## Filtered dwell extraction says colocalization is missing

Run the complete filtered workflow for the required channels:

```python
analysis.combine_spots_clusters(ch="ch0")
analysis.combine_spots_clusters(ch="ch1")
analysis.retrack()
analysis.recoloc_tracks()
```
